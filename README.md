# Arcwise Portfolio

Portfolio site for Jonathan Jackson Ameche (Arcwise), Roblox programmer.

Live at https://volticoil.github.io/arcwise-portfolio/

## Editing

- `arcwise-portfolio.html` is the page source.
- `index.html` is the built page that GitHub Pages serves. Regenerate it with `python3 build.py` after editing the source.
- `thumbs/` holds the game thumbnails and `videos/` holds the YouTube preview images.

Game thumbnails and video previews belong to their respective owners.
